# YOLO & Computer Vision Weights Directory

Folder ini dialokasikan untuk menyimpan berkas bobot model Machine Learning / Computer Vision:
- `yolov8n.pt` (Deteksi objek kendaraan & manusia)
- `best.pt` (Deteksi plat nomor kendaraan)
- `yolov8s.pt` (Model opsional YOLOv8 Small)

> [!NOTE]
> Sistem pendeteksi (`app/engine/analyzer.py`) secara otomatis mendukung pencarian berkas model baik di folder `weights/` maupun folder warisan `models/`.
